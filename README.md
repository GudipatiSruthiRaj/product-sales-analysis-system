# Product Sales Analysis System

## Overview
This project analyzes product sales data using Python, Pandas, MySQL, and Matplotlib.

## Technologies Used
- Python
- Pandas
- MySQL
- Matplotlib

## Features
- Category-wise revenue analysis
- Monthly sales trends
- Top-selling products
- Region-wise revenue analysis

## How to Run
1. Install required packages
2. Configure MySQL database
3. Run:
   python analysis.py
